---
title: VS Code で Flixa を使い始める
description: Flixa 拡張機能のインストールからサインイン、エージェントで最初の変更を加えるまでの手順です。
---

Flixa は Deni AI のコーディングエージェントで、VS Code の拡張機能として動きます。コードを読み、ファイルを編集し、コマンドを実行します。必要なときは実行前に確認を求めます。
Cursor、Windsurf、Antigravity でも使えます。

<Callout title="Deni AI アカウントでサインインしてください">
  Flixa はすべてのプランで使えますが、ゲストアカウントでは使えません。先に通常のアカウントでサインインしてください。
</Callout>

## 拡張機能をインストールする

拡張機能の名前は **Flixa**（発行元 `deniai`）です。お使いのエディターの拡張機能レジストリからインストールします。

| エディター | インストール先 |
| --- | --- |
| VS Code | [Visual Studio Marketplace](https://marketplace.visualstudio.com/items?itemName=deniai.flixa) |
| Cursor、Windsurf、Antigravity | [Open VSX Registry](https://open-vsx.org/extension/deniai/flixa) |

インストールすると、アクティビティバーに Flixa のアイコンが表示されます。

## サインインする

1. コマンドパレットで **Deni AI: Login** を実行します。
2. ブラウザで deniai.app の Flixa の承認ページが開きます。求められたらサインインします。
3. ページの確認コードが VS Code の通知（「Waiting for approval... Code: ...」）のコードと同じか確認します。
4. **承認** をクリックします。VS Code は自動で接続されるので、ページは閉じてかまいません。

接続されると、ステータスバーに `Deni AI: <プラン名>` と表示されます。
15 分以内に承認しないとタイムアウトします。その場合はもう一度 **Deni AI: Login** を実行してください。

サインインすると、アカウントに API キーが 1 つ作成されます。API キーは 5 つまで作成できます。
すでに 5 つある場合は、承認ページでどれか 1 つを取り消してから続けます。

### API キーでサインインする

1. [設定 › API キー](https://deniai.app/settings/api-keys) でキーを作成し、コピーします。
2. ステータスバーの **Deni AI: Not connected** をクリックします。
3. **Enter API Key manually** を選び、キー（`deni_` で始まる文字列）を貼り付けます。

## 最初の変更を頼む

1. アクティビティバーの Flixa アイコンをクリックしてチャットを開きます。**Flixa: Open Chat** コマンドでも開けます。
2. 入力欄の横のセレクターでモデルを選びます。モデルによっては推論の強さ（reasoning effort）も選べます。
3. モードが **Agent** になっているか確認します。モードは入力欄の **+** ボタンから切り替えられます。
4. してほしい変更を書いて送信します。
5. Flixa が許可を求めると、入力欄の上に **Allow** / **Deny** のカードが表示されます。
6. **Files Changed** の一覧で変更されたファイルを確認します。ファイルごとに残すか元に戻すかを選びます。すべて残すときは **Keep All** をクリックします。

| モード | 動作 |
| --- | --- |
| Agent | ファイルを読み書きし、コマンドを実行してタスクを進めます |
| Chat | 操作はせず、質問に答えるだけです |

知っておくと便利な機能は次のとおりです。

- `@` を入力すると、ワークスペースのファイルをコンテキストに追加できます。開いているファイルと選択範囲は自動で追加され、入力欄から外すこともできます。
- エージェントの実行中に送ったメッセージは順番待ちになり、実行が終わってから送られます。
- 送信済みの自分のメッセージは編集して送り直せます。
- チャットビューの上部に **Flixa: New Chat** と **Flixa: Chat History** があります。

## 承認モードを選ぶ

承認モードによって、どの操作に確認が必要かが変わります。**+** ボタン、`/approval`、**Flixa: Set Approval Mode** のどれかで変更できます。

| モード | シェルコマンド | そのほかの操作 |
| --- | --- | --- |
| All Approve | 確認なしで実行 | 確認なしで実行 |
| Auto | AI による安全チェックのあと実行 | 確認なしで実行 |
| Safe Approve（既定） | 毎回確認 | 確認なしで実行 |
| Manual Approve | 毎回確認 | 毎回確認 |

## スラッシュコマンド

入力欄で `/` を入力すると一覧が出ます。

| コマンド | 動作 |
| --- | --- |
| `/new` | 新しいチャットを始める |
| `/clear` | このチャットのメッセージを消す |
| `/compact` | このチャットのコンテキストを圧縮する |
| `/stop` | 実行中のエージェントを止める |
| `/agent`、`/chat` | Agent モード、Chat モードに切り替える |
| `/model [model-id]` | モデルを表示・変更する |
| `/approval [auto\|safe\|manual\|all]` | 承認モードを表示・変更する |
| `/help` | コマンドの一覧を表示する |

## エディターから編集する

- **Inline Edit**: エディターで `Ctrl+I`（macOS では `Cmd+I`）を押し、変更内容を入力します。先にコードを選択しておくと、Flixa はその部分を中心に編集します。
- **Implement Comment**: `// TODO: ...`、`// implement: ...`、`# TODO: ...`、`@flixa implement ...` のようなコメントを書くと、コメントの上に **Implement (Flixa)** が表示されます。クリックすると Flixa が実装します。

どちらも結果は差分で表示されるので、確認してから適用できます。

## 知っておきたい設定

Flixa の設定を開くには、チャットビューの設定メニューで **Open Settings** を選ぶか、VS Code の設定で `@ext:deniai.flixa` を検索します。

| 設定 | 既定値 | 内容 |
| --- | --- | --- |
| `flixa.agentApprovalMode` | `SAFE_APPROVE` | 既定の承認モード |
| `flixa.autoContext.enabled` | `true` | ワークスペースのファイル一覧、git status、`package.json`、`tsconfig.json`、開いているファイルをプロンプトに含めます |
| `flixa.autoContext.excludePatterns` | `node_modules`、`.git`、`dist` など | ファイル一覧から除外するファイルやフォルダー |
| `flixa.compactTokenThreshold` | `200000` | コンテキストがこの大きさ（推定トークン数）に達すると、チャットを自動で圧縮します。`0` で無効になります |

ほかの `flixa.autoContext.*` 設定では、コンテキストに含める内容や、ファイル一覧の深さと件数の上限を変えられます。

## プランと使用量

Flixa は Deni AI のプランに含まれる使用量で動きます。Free を含むすべてのプランで使えます。

- モデルごとに使用量の段階（Tier）があり、Tier が高いほど使用量の減りが速くなります。モデルセレクターには `Tier 3 · 2x` のように表示されます。
- 一部のモデルには上位プランが必要です。その場合は「Plus plan or higher required」や「Pro plan required」と表示され、クリックすると請求ページが開きます。
- ステータスバーに今のプランが表示されます。この表示をクリックするか、チャットビューの設定メニューで **Usage** を選ぶと、残りの使用量を確認できます。
- 同じメニューの **Plan** から [設定 › 請求](https://deniai.app/settings/billing) を開けます。

## サインアウトする

コマンドパレットで **Deni AI: Logout** を実行します。

## うまくいかないとき

**ステータスバーに「Deni AI: Not connected」と表示される**

サインインしていません。この表示をクリックして **Login with Deni AI** を選んでください。

**承認ページに「サインインが必要です」と表示される**

ゲストアカウントを使っています。通常のアカウントでサインインしてから、もう一度承認してください。

**モデルに「Login required」と表示される**

先にサインインしてください。ロックされたモデルをクリックしてもサインインを始められます。
