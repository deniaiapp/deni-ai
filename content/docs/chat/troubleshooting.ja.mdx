Deni AI のチャットで表示されるメッセージと、その原因と対処法をまとめています。

ここにないメッセージが表示されたときや、対処法を試しても解決しないときは、[お問い合わせ](/ja/contact)ください。表示されたメッセージ、使っていたモデル、起きたおおよその時刻をお知らせください。

## チャットのエラーメッセージ

リクエストに失敗すると、会話の下に赤い **エラー** のカードが表示されます。

| メッセージ | 対処法 |
| --- | --- |
| 「ご利用のプランの使用上限に達しました。」 | 今月の利用枠を使い切っています。続ける方法は[利用枠の上限の通知](#利用枠の上限の通知)の表のとおりです。 |
| 「…のモデルは現在利用できません。後ほどお試しください。」 | そのプロバイダーのモデルに問題が起きています。しばらく待つか、別のプロバイダーのモデルに切り替えてください。 |
| 「…のモデルは現在アクセスが集中しています。後ほどお試しください。」 | プロバイダーが混み合っています。数分後にもう一度試すか、モデルを切り替えてください。 |
| 「…のコンテキストウィンドウを超えました。新しいチャットを開始するか、以前のメッセージやファイルを減らしてください。」 | 会話とファイルが、モデルが一度に読める長さを超えています。新しいチャットを始めるか、大きなファイルを外すか、コンテキストウィンドウの大きいモデルをお選びください。 |
| 「ゲストセッションではFast、Pro、Deep Researchを利用できません。ログインしてご利用ください。」 | **詳細リサーチ** をオフにするか、サインインしてください。 |
| 「ゲストセッションではこの長さの会話は利用できません。新しいチャットを始めるか、ログインして続行してください。」 | ゲストのチャットには長さの上限があります。新しいチャットを始めるか、サインインしてください。 |
| 「ゲストセッションではこのサイズのファイルは利用できません。添付ファイルを削除するか、ログインして送信してください。」 | ファイルを外すか、小さいファイルに替えるか、サインインしてください。 |
| 「予期しないエラーが発生しました。」 | 原因はいくつか考えられます。[予期しないエラーが発生したとき](#予期しないエラーが発生したとき)の手順を順にお試しください。 |

エラーのカードには再試行のボタンがありません。再試行するときは、メッセージを再度お送りください。

### 予期しないエラーが発生したとき

このメッセージは次のようなさまざまな原因で表示されます。

- 短い時間にメッセージを送りすぎた（1 分に 30 回より多い）
- メッセージが Deni AI に届く前に接続が切れた
- 今のプランでは使えないモデルを選んでいる
- 添付したファイルを読み込めない
- サインインが切れている

次の順にお試しください。

1. 1 分ほど待ってから、メッセージを送り直します。
2. インターネットの接続を確認して、ページを再読み込みします。
3. 別のモデルを選びます。
4. 添付ファイルがある場合は、外してから送り直します。
5. サインアウトして、もう一度サインインします。
6. 新しいチャットを始めます。

それでも続く場合は、使っていたモデルと送ろうとした内容を添えて[お問い合わせ](/ja/contact)ください。

## 利用枠の上限の通知

利用枠の残りが少なくなったときや、なくなったときは、メッセージ欄の上に通知が表示されます。

| 通知 | 対処法 |
| --- | --- |
| 「残りが少なくなっています」 | 今月の利用枠が残りわずかです。プランをアップグレードするか、ティアの低いモデルをご利用ください。 |
| 「使用制限に達しました」 | **プランをアップグレード** を選ぶか、毎月 1 日 00:00（UTC）のリセットをお待ちください。 |
| 「続けるには Max Mode クレジットを購入してください」 | **クレジットを購入** を選びます。 |
| 「Max Mode を有効にして続行」 | クレジットが残っています。**Max Mode を有効にする** を選びます。 |
| 「現在、無料枠が制限されています。…」 | **カードを確認** を選ぶと制限が解除されます。カードに請求は発生しません。 |

上限に達している間は、送信ボタンと **再試行** が使えません。
アップグレードやクレジットの購入のあとは、**利用状況を更新** をお選びください。

回答の途中で Max Mode のクレジットがなくなると、回答はそこで止まります。それまでに書かれた内容は残ります。

| **Max Mode を有効にする** を選んだあとのメッセージ | 対処法 |
| --- | --- |
| 「Max Mode クレジットは、有効な有料プランで利用できます。」 | Max Mode を使うには、更新が続いている Go、Plus、Pro のいずれかのプランが必要です。[設定 › 請求](https://deniai.app/settings/billing) で契約の状態をご確認ください。 |
| 「チームの Max Mode を管理できるのは組織のオーナーだけです。」 | チームのオーナーにご依頼ください。 |

利用枠の数え方は [プランと使用量](/ja/billing/plans-and-usage) で説明しています。

## モデル

モデルの選択画面では、次の表示が出ることがあります。

- 警告のアイコンと「このモデルは現在利用できません。」は、そのモデルの直近の稼働チェックが失敗したことを示します。別のモデルをお選びください。
- 「このモデルは … に提供終了予定です。」のように日付が出ているモデルは、提供が終わる予定です。その日までに別のモデルに切り替えてください。
- 「さらにモデルを使うにはログインしてください」はゲストに表示されます。サインインすると、ご利用いただけるモデルが増えます。
- 「カードを認証すると、より多くのモデルが利用できるようになります」は Free プランで表示されます。[設定 › 請求](https://deniai.app/settings/billing) でカードを確認してください。
- 「利用可能なモデルがありません」は、モデルの一覧を読み込めなかったことを示します。ページを再読み込みしてください。

ステータスページはありません。各モデルの今の状態はモデルの選択画面のアイコンでご確認いただけます。

## ファイルのアップロード

ファイルは追加した時点でアップロードが始まります。アップロードに失敗すると、ファイルの下に赤い文字が表示されます。

<Callout title="送信する前に赤い文字がないかご確認ください">
  ファイルにエラーが出たまま送信すると、そのファイルを除いてメッセージが送られます。ファイルを外して問題を直してから、もう一度追加してください。
</Callout>

| メッセージ | 対処法 |
| --- | --- |
| 「アップロード中...」 | 終わるまでお待ちください。アップロード中は送信できません。 |
| 「添付ファイルが大きすぎます。」 | 画像と PDF は 10 MB 以下にしてください。ファイルを圧縮するか分割してください。 |
| 「テキストファイルが大きすぎます（最大2MB）。」 | テキストとコードのファイルは 2 MB 以下にしてください。ファイルを分割するか、必要な部分だけを貼り付けてください。 |
| 「この形式の添付ファイルには対応していません。」 | PDF、PNG、JPEG のいずれかに変換してください。テキストファイルは UTF-8 で保存し直してください。 |
| 「このブラウザでは HEIC 画像を読み込めません。JPEG または PNG に変換してください。」 | 画像を変換するか、Safari でお試しください。 |
| 「この画像形式には対応していません。JPEG、PNG、WebP、PDF を使用してください。」 | 画像をこれらの形式に変換してください。 |
| 「添付ファイルの保存容量がいっぱいです（… のうち … を使用中）。…」 | 添付ファイルのあるチャットを削除するか、プランをアップグレードしてください。プランごとの容量は[添付ファイルの保存容量](#添付ファイルの保存容量)の表にあります。 |
| 「アップロードが多すぎます。しばらくしてからお試しください。」 | 最大 10 分待ってから、もう一度お試しください。 |
| 「添付ファイルのアップロードに失敗しました。」 | ファイルを外して、もう一度追加してください。 |
| 「サーバーに接続できませんでした。ネットワーク接続を確認して、もう一度お試しください。」 | インターネットの接続を確認して、ファイルを追加し直してください。 |

### 添付できるファイル

| 種類 | 形式 | サイズの上限 |
| --- | --- | --- |
| 画像 | JPEG、PNG、WebP。HEIC、GIF、AVIF、BMP は、ブラウザーが読み込める場合にブラウザーで変換します。 | 10 MB |
| PDF | PDF | 10 MB |
| テキストとコード | `.txt`、`.md`、`.csv`、`.json`、`.html`、`.py`、`.ts` などのファイル | 2 MB |

Shift_JIS や UTF-16 のテキストファイルは UTF-8 に変換されるので、サイズが大きくなることがあります。EUC-JP や GBK などの文字コードのファイルは読み込めません。

### 添付ファイルの保存容量

添付したファイルはチャットと一緒に保存され、添付ファイルの保存容量を使います。

| ゲスト | Free | Go | Plus | Pro |
| --- | --- | --- | --- | --- |
| 20 MB | 100 MB | 200 MB | 500 MB | 1 GB |

チャットを削除すると、そのチャットに添付したファイルも削除されます。

## 回答が止まったときや終わらないとき

### 停止を選んだとき

回答はそこで止まり、それまでに書かれた内容はチャットに残ります。利用枠に数えられるのは、書かれた分だけです。

最後まで回答させたいときは、回答の下の **再試行** から **再生成** をお選びください。

### ページを閉じたときや接続が切れたとき

メッセージが届いたあとに接続が切れた場合、Deni AI は回答を書き続けます。
ページに戻ると「応答を待っています...」と表示され、回答ができあがると表示されます。メッセージを送り直す必要はありません。

メッセージが届く前に接続が切れた場合は、「予期しないエラーが発生しました。」と表示されます。メッセージを再度お送りください。

### 回答の途中でエラーが出たとき

エラーの前に書かれた内容はチャットに残り、その下にエラーのカードが表示されます。**再試行** から **再生成** を選んでもう一度試すか、モデルを切り替えてください。

何も書かれないうちにエラーが出た場合は、**再試行** のボタンが表示されません。メッセージを再度お送りください。

### 再試行のメニュー

回答の下の **再試行** から、次の操作ができます。

- **再生成** で回答を作り直す
- **回答を詳しくする** か **回答を短くする**
- **Web検索を使う** か **詳細リサーチを実行**
- **モデルを変更** して、別のモデルで回答し直す
- 回答をどう直してほしいかを入力する

作り直す前の回答も消えずに残ります。回答の下の矢印で切り替えてご覧いただけます。

## Web 検索とページの読み込み

| メッセージ | 対処法 |
| --- | --- |
| 「検索に失敗しました」 | Web 検索が完了しませんでした。もう一度ご質問ください。利用枠を使い切っていると、Web 検索も使えません。検索 1 回につき 10,000 ユニットを使います。 |
| 「ページを開けませんでした」 | サイトにブロックされた、ページが大きすぎたなどの理由で、ページを開けませんでした。別のリンクを試すか、ページの文章をチャットに貼り付けてください。 |

## そのほかのメッセージ

| メッセージ | 対処法 |
| --- | --- |
| 「チャットの開始中にエラーが発生しました。」 | もう一度お試しください。プライベートウィンドウを使っている場合は、サイトにデータの保存を許可するか、通常のウィンドウで開いてください。 |
| 「会話の削除に失敗しました。もう一度お試しください。」 | もう一度お試しください。 |
| 「チャットの移動に失敗しました。もう一度お試しください。」 | もう一度お試しください。 |
| 「コピーに失敗しました。リンクを選択して手動でコピーしてください。」 | ブラウザーがコピーを許可しませんでした。リンクを選択して、手動でコピーしてください。 |
| 「画像生成は利用できなくなりました。」または「動画生成は利用できなくなりました。」 | これらの機能は提供を終了しました。このメッセージは、以前にこれらの機能を使ったチャットに表示されます。 |
