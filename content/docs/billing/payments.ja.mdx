プランは [設定 › 請求](https://deniai.app/settings/billing) で管理します。
決済は Stripe で処理され、お支払いにはクレジットカードを使います。

- **申し込み・プランの変更・解約**: 設定 › 請求の画面で行います。
- **請求書・カード・請求先情報**: **管理** から開く Stripe のカスタマーポータルで確認・変更します。

ゲストはプランを申し込めません。先にサインインしてください。ゲストのチャットを登録後のアカウントに引き継ぐ方法は、[チャットを引き継ぐ](/ja/account/guest-accounts#チャットを引き継ぐ)にあります。
各プランの内容は [プランと使用量](/ja/billing/plans-and-usage) にまとめています。

## 料金と通貨

料金は設定 › 請求のプランカードに表示されます。

- **日本からアクセスした場合**は円で、ほかの地域からアクセスした場合は米ドルで表示されます。
- 請求はプランカードに表示された通貨で行われます。
- **年額** のプランには、月額払いと比べてどれだけお得か（「○%お得」）と、月あたりの金額が表示されます。
- **Max Mode クレジット**は米ドル建てです。チェックアウトでは現地通貨で表示されることがあります。

表示される通貨はアカウントの言語設定ではなくアクセスしている地域で決まります。

## 申し込む

1. [設定 › 請求](https://deniai.app/settings/billing) の Plus または Pro のカードで、**月額** か **年額** を選びます。Go は月額のみです。
2. **購読する** を押します。
3. カード情報と請求先住所を入力します。クーポンコードがある場合は入力して **適用** を押します。
4. 利用規約に同意して、**サブスクリプションを開始** を押します。

カードによっては、本人認証（3D セキュア）を求められます。
支払いが完了するとすぐに新しいプランをご利用いただけるようになり、画面に領収書が表示されます。

まだ一度も支払ったことがないアカウントでは、期間限定の割引（「%オフ」）がプランカードに表示されることがあります。

## プランを変更する

アップグレード、ダウングレード、月額と年額の切り替えは、すべて次の手順で行います。

1. 変更先のプランのカードで **プランを変更** を押します。Plus と Pro では先に **月額** か **年額** を選びます。
2. ダイアログで **推定料金** を確認します。プランの差額は日割りで調整されます。
3. 「見積もり金額を確認し、プラン変更に同意します。」にチェックを入れて、**確認** を押します。

変更はすぐに反映され、日割りの差額もその場で請求されます。
支払いが完了しなかった場合、プランは変更されません。

月間の利用枠もすぐに新しいプランの利用枠に切り替わります。その月にすでに使った分は、新しい利用枠の使用量としてそのまま数えられます。

## 解約する

1. [設定 › 請求](https://deniai.app/settings/billing) の「現在のプラン」カードで、**サブスクリプションを解約** を押します。
2. 確認画面で **サブスクリプションを解約** を押します。

プランは現在の請求期間の終わりまでご利用いただけます。「現在のプラン」カードには「（*日付*に解約）」と表示されます。
その日を過ぎると、Free プランに戻ります。

それまでは **再開する** を押せば、サブスクリプションを続けていただけます。
解約を予約している間は、次の点にご注意ください。

- プランを変更できません。プランカードには **再開して変更** と表示されます。
- Max Mode はご利用いただけません。使わなかったクレジットは有効期限までアカウントに残ります。

<Callout title="返金について">
  有料プランは支払うとすぐにご利用いただけるデジタルサービスのため、法令で必要な場合を除き、原則として返金できません。使用済みの Max Mode クレジットも返金できません。正式な条件は [利用規約](https://deniai.app/ja/legal/terms) と [特定商取引法に基づく表記](https://deniai.app/ja/legal/tokusho) に定めています。
</Callout>

## 請求書・カード・請求先情報

「現在のプラン」カードの **管理** を押すと、Stripe のカスタマーポータルが開きます。ポータルでは次のことができます。

- これまでの請求書の確認とダウンロード
- 支払いに使うカードの変更
- 請求先のメールアドレス、名前、住所、税 ID の変更

ポータルではプランを変更できません。設定 › 請求の **プランを変更** をご利用ください。

## チームのプラン

Pro for Teams の請求は [設定 › チーム](https://deniai.app/settings/team) で別に管理します。チームの契約と請求は [Pro for Teams を始める](/ja/teams/pro-for-teams) で説明しています。

## うまくいかないとき

**「すでに有効なサブスクリプションがあります。プランを変更するか、先にキャンセルしてください。」と表示される**

個人で契約できるサブスクリプションは 1 つまでです。別のプランに移るときは、そのプランのカードの **プランを変更** をご利用ください。

**プランカードに「再開して変更」と表示される**

サブスクリプションの解約が予約されています。「現在のプラン」カードの **再開する** を押してから、プランを変更してください。

**プランの変更に失敗する**

変更にともなう支払いが完了していません。**管理** からカードを更新して、もう一度お試しください。

**チェックアウトが表示されない**

- 「Stripe.js の読み込みに失敗しました」と表示される場合は、広告ブロッカーなど Stripe をブロックしている拡張機能を無効にしてから、ページを再読み込みしてください。
- 「チェックアウトセッションの有効期限が切れました」と表示される場合は、[設定 › 請求](https://deniai.app/settings/billing) に戻って、もう一度 **購読する** を押してください。

**アカウントを削除できない**

先にサブスクリプションを解約してください。

**請求に心当たりがない、または請求内容がおかしい**

[お問い合わせ](https://deniai.app/ja/contact) からご連絡ください。
