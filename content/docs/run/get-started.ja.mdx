[Deni Run](https://run.deniai.app) は AI のチームメイトに仕事を任せる Web アプリです。
チームメイトはそれぞれ専用のコンピューターで作業します。コンピューターには、あなたのアカウントだけが使うブラウザー、ファイルのワークスペース、Linux のターミナルがあります。
調べもの、フォームの入力、ファイルの整理、スクリプトの実行を、自分のパソコンに触れずに任せられます。

Deni Run は Deni AI のすべてのプランに含まれていて、Deni Run だけの料金はありません。Deni AI チャットや Flixa と同じ毎月の利用枠を使います。

## サインイン

1. [run.deniai.app](https://run.deniai.app) を開き、**Deni AI で続行**、**Googleで続行**、**GitHubで続行** のいずれかを選びます。**パスキーでログイン** も使えます。
2. パスキー、メールで届くコード、認証アプリのいずれかで、もう一度本人確認をします。Deni Run では、この 2 段階目の確認が必ず求められます。

パスキーは登録したサイトでしか使えません。
メールのコードは 1 つのアカウントにつき 15 分に 5 回まで送れます。

## Deni AI アカウントを連携する

Deni Run は Deni AI アカウントのプランを使います。アカウントを連携するまで、チームメイトは作業を始められません。

**Deni AI で続行** でサインインした場合は、すでに連携されています。それ以外の方法でサインインした場合は、次の手順で連携します。

1. Deni Run の **アカウント** を開きます。
2. **Deni AI アカウントを連携** を選び、Deni AI にサインインします。

連携すると、**アカウント** に **プランと使用量を管理** が表示されます。選ぶと Deni AI の [設定 › 請求](https://deniai.app/settings/billing) が開きます。

<Callout title="ゲストアカウントでは Deni Run を使えません">
  Deni AI のゲストアカウントは連携できません。先に Deni AI に登録してください。詳しくは [ゲストアカウント](/ja/account/guest-accounts) を見てください。
</Callout>

## チームメイトに仕事を任せる

Deni Run には Chief、Research、Operations などのチームメイトが用意されています。自分でチームメイトを作るときは、**新しいチームメイト** を選びます。
チームメイトはそれぞれ自分のメモリ、スキル、ルーティンを持っています。

1. チームメイトを選び、任せたい仕事を書きます。調べもの、フォームの入力、ファイルの整理などです。
2. チームメイトが作業している画面を、その場で見られます。
3. 確認を求められたら、危険な操作を承認します。結果はワークスペースに保存されます。

サイトへのサインイン、二要素認証のコード、CAPTCHA が必要になったときは、画面のブラウザーを自分で操作してその手順を済ませ、チームメイトに戻します。

### 承認

読み取りだけの操作は確認なしで実行されます。
ファイルの削除や、内容を変えるコマンドの実行など、それ以外の操作は承認を待ちます。信頼できる操作で確認を省きたいときは、承認の画面で **常に許可** を選ぶか、**プラグイン** でそのツールの **常に許可** をオンにします。
自分で追加した MCP サーバーの呼び出しは、そのツールを許可していない限り、毎回承認が必要です。

### モデル

モデルは選択画面で選びます。

| モデル | もとのモデル | 向いている用途 |
| --- | --- | --- |
| Run | Claude Sonnet 5.5 | 速く、利用枠の使用量が少ない |
| Run+ | Claude Opus 5.5 | 難しい仕事 |

どちらのモデルにも、推論の強度が **デフォルト**、**高**、xhigh、**最大** の 4 段階あります。強度を上げるほど、利用枠を多く使います。選択画面には、それぞれの選択肢が Run のデフォルトのおよそ何倍の利用枠を使うかが表示されます。

### チームメイトの上限

| プラン | チームメイト |
| --- | --- |
| Free | 5 人まで |
| Go | 10 人まで |
| Plus | 15 人まで |
| Pro | 25 人まで |

上限に達すると「チームメイトの上限に達しました」と表示されます。チームメイトを増やすには、Deni AI のプランをアップグレードしてください。

### ファイル

1 つのメッセージに 10 MB 以下のファイルを 10 個まで添付できます。添付したファイルはチームメイトのワークスペースに保存されます。

## アプリを接続する

**プラグイン** でアプリを接続すると、チームメイトがあなたに代わって検索、閲覧、下書き、送信をできるようになります。
接続できるのは、Gmail、Google ドライブ、GitHub、Discord、Slack、Notion、Linear、Jira、Sentry、Stripe と、自分の MCP サーバーです。
どのアプリも接続するまではオフになっています。

1. **プラグイン** を開き、**コネクタを探す** を選びます。
2. アプリを検索して **接続** を選びます。

誰も見ていないときに裏で動く作業では、接続したアプリの読み取り専用のツールだけを使えます。

### Discord

Discord のダイレクトメッセージで、チームメイトと話すこともできます。

1. **プラグイン** で **Discord の DM でチームメイトと話せます** を探し、**連携する** を選びます。
2. 表示されたコードを、Discord のダイレクトメッセージで Deni Run のボットに送ります。コードは 1 回しか使えず、10 分で期限が切れます。

Discord のサーバーのチャンネルには対応していません。サイトへのサインインなど、ブラウザーが必要な手順は Deni Run の Web アプリで済ませてください。

## 利用枠

Deni Run は Deni AI のプランの毎月の利用枠を、Deni AI チャットや Flixa と共有して使います。数えるのは次の 3 つです。

- モデルの利用
- チームメイトのブラウザーを使った時間
- チームメイトのコンピューターを使った時間

Deni Run は各手順を実行したあとでコストを数えます。そのため、残りの利用枠を少し超えて作業が進むことがあります。

| | Free | Go | Plus | Pro |
| --- | --- | --- | --- | --- |
| 毎月の利用枠（共有） | 2,000 万ユニット | 6,000 万ユニット | 2 億ユニット | 4 億ユニット |

利用枠は毎月 1 日 00:00（UTC）にリセットされます。Deni Run の **プランと使用量** では、今月使った利用枠の割合が、Deni AI Chat、Flixa、Deni Run の内訳つきで表示されます。
正確な数は [設定 › 請求](https://deniai.app/settings/billing) の **利用状況** カードで確認してください。

利用枠を使い切ると「今月の利用枠を使い切りました」と表示され、リセットまでチームメイトは作業できません。
利用量のリセット権でリセットされるのは Deni AI チャットと Flixa の使用量だけで、Deni Run の使用量はリセットされません。Max Mode のクレジットも Deni Run には使われません。

プランを変えるときは、**Deni AI でプランを管理** を選びます。プランは Deni AI で購入します。詳しくは [プランと使用量](/ja/billing/plans-and-usage) を見てください。

## データの扱い

- ワークスペースのファイル、ブラウザーのセッション、コンピューターは、アカウントごとに分けられています。
- Deni AI が受け取るのは、Deni AI のアカウント ID と、使った分のコストです。
- メッセージは OpenRouter と、OpenRouter が振り分けるモデルの提供元で処理されます。モデルの学習には使われません。
- Deni Run はデータを広告に使ったり販売したりしません。
- 接続したアプリのトークンは、暗号化して保存されます。

### データのダウンロードと削除

**アカウント** で、次の操作ができます。

- **JSONをダウンロード** で、チームメイト、会話、スキル、ルーティン、使用量をダウンロードします。API キーは含まれません。
- **アカウントを削除** で、Deni Run のログイン情報、ワークスペースのファイル、会話、チームメイト、請求の記録を削除します。確認のため `DELETE` と入力します。

Deni Run のアカウントを削除しても、Deni AI のアカウントは削除されません。[データとプライバシー](/ja/account/data-and-privacy)を見てください。
