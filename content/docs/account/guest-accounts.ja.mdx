---
title: ゲストアカウント
description: アカウントなしでできること、ゲストの使用量の上限、登録時にゲストのチャットを引き継ぐ方法を説明します。
---

Deni AI はアカウントを作らなくてもお試しいただけます。[サインイン画面](https://deniai.app/auth/sign-in)で **ゲストとして続行** を選ぶと、すぐにチャットを始めていただけます。
始める前に、簡単なセキュリティチェックが表示されることがあります。

ゲストアカウントを使っている間は、アカウントメニューに名前やメールアドレスの代わりに **ゲスト**、**ゲストアカウント** と表示されます。

ゲストアカウントは使い始めたブラウザーにひも付いています。作ったチャットなどを残すには、同じブラウザーで登録またはサインインしてください。

<Callout title="ログアウトするとゲストのチャットは削除されます">
  ゲストアカウントには再びサインインできません。ログアウトすると、ゲストアカウントとそのチャットは削除されます。
  チャットを残したい場合は、[先に登録またはサインインしてください](#チャットを引き継ぐ)。
</Callout>

## ゲストでできること

- GPT-6 Luna とのチャット
- Web 検索
- ファイルの添付（添付ファイルの保存容量は 20 MB まで）

## 使用量の上限

ゲストには **1,000,000 usage units**（1M）が付与されます。この使用量はリセットされません。

- チャットはサインイン済みのアカウントと同じく、使ったトークン数に応じて units を消費します。
- Web 検索は 1 回につき 10,000 units を消費します。
- 残りの使用量はアカウントメニューの **利用状況** でご確認いただけます（「残り◯%」の形で表示されます）。

使い切ったあとは、登録すればチャットを続けていただけます。登録したアカウントでは、ゲストの使用量の残りではなく、そのアカウントのプランの使用量を使います。
プランごとの利用枠は [プランと使用量](/ja/billing/plans-and-usage) にまとめています。

ゲストでは、1 回のメッセージにも上限があります。

| メッセージ | 対処法 |
| --- | --- |
| 「ゲストセッションではこの長さの会話は利用できません。…」 | 新しいチャットを始めるか、サインインしてください。 |
| 「ゲストセッションではこのサイズのファイルは利用できません。…」 | 添付ファイルを外すか、サインインしてから送信してください。 |

また、ゲストでは回答 1 回あたりの長さに上限があり、推論の強さ（reasoning effort）は medium までになります。

## ゲストではできないこと

| 機能 | ゲストの場合 |
| --- | --- |
| GPT-6 Luna 以外のモデル | 「ゲストセッションではGPT-6 Lunaのみ利用できます。他のモデルを使うにはログインしてください。」 |
| Fast、Pro、Deep Research | 「ゲストセッションではFast、Pro、Deep Researchを利用できません。ログインしてご利用ください。」 |
| モデルの比較 | ログインして Pro（または Team プラン）にする必要があります。 |
| 設定ページ（`https://deniai.app/settings/...`。プランや支払いの設定も含みます） | チャット画面に戻されます。 |
| API キーと Flixa | 「ゲストアカウントではAPIキーの作成やFlixa拡張機能の利用はできません。」サインインすると、[Flixa を外部のコーディングツールで使う](/ja/flixa/external-tools) の手順でご利用いただけます。 |
| Deni AI のアカウントでほかのアプリにサインインする | 「ゲストアカウントでは他のアプリにサインインできません。続行するには登録済みのアカウントでサインインしてください。」 |
| チーム | ゲストはチームを作成できません。 |
| ほかのサービスからのチャットのインポート | 使えません。 |
| メールアドレスの変更、パスキーの追加、Google や GitHub の連携、二要素認証の設定 | 使えません。登録してからご利用ください。ゲストにはアカウント設定の **セキュリティ** タブが表示されません。 |
| メモリの自動保存 | ゲストのチャットからはメモリが保存されません。 |

## チャットを引き継ぐ

ゲストアカウントを使っているのと **同じブラウザーで** 登録またはサインインすると、ゲストのデータがそのアカウントに移ります。

1. アカウントメニューから **登録してチャットを残す** を選びます。すでにアカウントをお持ちの場合は、[サインイン画面](https://deniai.app/auth/sign-in)からサインインします。
2. メールアドレスとパスワード、メールのサインインリンク、Google、GitHub、パスキーのどれかで登録またはサインインします。
   メールアドレスで登録した場合は、確認用のリンクを同じブラウザーで開いてください。

アカウントに移るのは、次のデータです。

- チャット
- モデルの比較
- プロジェクトとそのファイル
- 添付ファイル
- メモリ
- パーソナライズの設定（アカウント側にすでに設定がある場合は、アカウントの設定が残ります）

ゲストの使用量は移りません。アカウントではそのアカウントのプランの使用量を使います。

データが移ったあと、ゲストアカウントは削除されます。

**二要素認証を使っているアカウントの場合**: メールアドレスとパスワードでサインインすると、ゲストのデータは移らず、ゲストアカウントは削除されます。

登録にご利用いただけるメールアドレスは、[登録できるメールアドレス](/ja/account/sign-in-trouble#登録できるメールアドレス)にまとめています。

## 登録しなかった場合

次の場合、ゲストアカウントとその中のデータは自動的に削除されます。

- ゲストアカウントからログアウトしたとき
- 1 週間ほど使わなかったとき

ログアウトする前には、「ゲストアカウントからログアウトしますか？」という確認が表示されます。

データの扱いは [データとプライバシー](/ja/account/data-and-privacy) で説明しています。
