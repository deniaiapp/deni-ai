Deni AI のサインイン方法と、エラーが出たときの対処法をまとめています。

<Callout title="Gmail は Google か GitHub でサインインしてください">
  Gmail アドレスでは、パスワードやメールのサインインリンクを使ってアカウントを作成できません。
  **Google で続行** か **GitHub で続行** をご利用ください。GitHub で登録するときの注意点は [Gmail アドレス](#gmail-アドレス)にあります。
</Callout>

## サインイン方法

サインインは [deniai.app/auth/sign-in](https://deniai.app/auth/sign-in) から、新規登録は [deniai.app/auth/sign-up](https://deniai.app/auth/sign-up) から行います。

| 方法 | ボタン・リンク |
| --- | --- |
| メールアドレスとパスワード | **サインイン** |
| メールのサインインリンク | **マジックリンク で続行**: サインイン用のリンクをメールでお送りします。リンクの有効期限は 5 分です。 |
| Google | **Google で続行** |
| GitHub | **GitHub で続行** |
| パスキー | **パスキー で続行** |
| アカウントなし | **ゲストとして続行**。できることと制限は [ゲストアカウント](/ja/account/guest-accounts) で説明しています。 |

パスキーを使うには、先に [アカウント › セキュリティ](https://deniai.app/account/security) の **パスキー** で **パスキーを追加** を選び、登録しておきます。

## 登録できるメールアドレス

新しくアカウントを作れるのは、次のメールアドレスです。

- 主要なメールサービス: Outlook、Hotmail、Live、iCloud、Yahoo、Proton、AOL、Zoho、Fastmail、HEY、Tuta、GMX、Yandex、Mail.ru、QQ、163、Naver、Daum、Kakao、国内の携帯キャリアのアドレス（docomo、au、SoftBank など）ほか
- 教育機関のアドレス: `.edu`、`.ac.jp`、`.ed.jp`、`.ac.uk`、`.sch.uk`、`.edu.au`、`.ac.nz`、`.ac.kr`、`.edu.tw`、`.edu.sg`、`.edu.hk`
- 勤務先のアドレス: 勤務先が Deni AI の有料チームプランを使っていて、そのメールドメインを確認済みの場合

Google や GitHub で登録する場合も同じです。Google や GitHub から Deni AI に共有されるメールアドレスが、上の条件を満たしている必要があります。
たとえば会社のドメインの Google アカウントは、チームがそのドメインを確認していない限り登録できません。

すでにアカウントをお持ちの場合は、メールアドレスのドメインが登録の対象から外れても、引き続きサインインいただけます。

ほかのドメインの追加をご希望の場合は、[お問い合わせ](https://deniai.app/ja/contact)ください。

### Gmail アドレス

Gmail アドレス（`gmail.com` と `googlemail.com`）で登録できるのは、**Google で続行** と **GitHub で続行** だけです。

GitHub で登録すると、GitHub で選んでいるメールアドレスが Deni AI に共有されます。
そのアドレスが `+` タグや不自然なドットを含む Gmail アドレスの場合は、エイリアスとみなされて登録できません。GitHub 側で通常の Gmail アドレスを使うか、**Google で続行** をご利用ください。

### エイリアスのアドレス

メールアドレスで登録する場合、`+` タグ（`name+news@outlook.com` など）や不自然なドットを含むアドレスは使えません。普段お使いのアドレスでご登録ください。

## エラーメッセージと対処法

| メッセージ | 対処法 |
| --- | --- |
| 「メールアドレスまたはパスワードが正しくありません」 | 入力内容を確認して、もう一度お試しください。Google、GitHub、パスキーで登録した場合は、その方法でサインインしてください。パスワードを追加したいときは、[パスワードを再設定する](#パスワードを再設定する)の手順で設定いただけます。 |
| 「メールアドレスが確認されていません」 | **メールを確認** の画面が表示され、新しい確認リンクが送られます。リンクを開くとサインインが完了します。メールが届かないときの対処法は [メールアドレスの確認](#メールアドレスの確認) にあります。 |
| 「Gmail アドレスの場合は、Google または GitHub でログインしてください。…」 | **Google で続行** か **GitHub で続行** をご利用ください。 |
| 「このメールアドレスはエイリアス（+タグや不自然なドット）のようです。…」 | `+` タグのない、普段のアドレスをご利用ください。 |
| 「主要なメールプロバイダー（Outlook、iCloud、Proton など）または教育機関のメールアドレス…」 | このアドレスでは新規登録できません。ご利用いただけるアドレスは[登録できるメールアドレス](#登録できるメールアドレス)にまとめています。 |
| 「有効なメールアドレスを入力してください。」 | アドレスに入力ミスがないかご確認ください。 |
| 「The password you entered has been compromised. Please choose a different password.」 | 過去のデータ漏えいで見つかったパスワードです。別のパスワードをお使いください。 |
| 「CAPTCHA を完了してください」または「CAPTCHA の認証に失敗しました。もう一度お試しください」 | フォームのセキュリティチェックを完了してから、もう一度送信してください。 |
| 「リクエストが多すぎます。しばらくしてからもう一度お試しください」 | 少し待ってから、もう一度お試しください。 |
| 「このネットワークから作成されたアカウントが多すぎます。しばらくしてからもう一度お試しください。」 | 時間をおいて、もう一度ご登録ください。 |

### Google・GitHub でのエラー

Google や GitHub でのサインインに失敗すると、サインイン画面に戻り、**ログインできませんでした** というメッセージと理由が表示されます。

| メッセージ | 対処法 |
| --- | --- |
| 「ログインがキャンセルされたか、時間がかかりすぎました。もう一度お試しください。」 | 最初からやり直してください。 |
| 「ログインが別のタブで開始されたか、時間がかかりすぎました。このページからもう一度お試しください。」 | メッセージが表示されたページから、もう一度お試しください。 |
| 「このメールアドレスは別のログイン方法で登録されています。…」 | 以前と同じ方法でサインインしてから、[アカウント › セキュリティ](https://deniai.app/account/security) の **連携済みアカウント** で Google や GitHub を連携してください。 |
| 「プロバイダーからメールアドレスが共有されませんでした。…」 | Google や GitHub 側でメールアドレスを Deni AI に共有するよう設定するか、別のサインイン方法をご利用ください。 |
| 「プロバイダーからプロフィールを取得できませんでした。もう一度お試しください。」 | もう一度お試しください。 |
| 「問題が発生しました。もう一度お試しください。（エラー: …）」 | もう一度お試しください。繰り返し表示される場合は、エラーコードを添えて[お問い合わせ](https://deniai.app/ja/contact)ください。 |

最初の表にある Gmail、エイリアス、メールサービスのメッセージが、Google や GitHub でのサインインで表示されることもあります。

## メールアドレスの確認

メールアドレスとパスワードで登録すると、確認用のリンクがメールで届きます。
リンクを開くと登録が完了し、そのままサインインされます。リンクの有効期限は 1 時間です。

- メールが届かないときは、迷惑メールフォルダを確認してから、**メールを確認** の画面で **再送信** を選んでください。
- 確認前にサインインしようとすると、新しいリンクが送られ、**メールを確認** の画面が表示されます。

サービス側でメール送信がオフになっていると、登録後に確認の手順はなく、そのままサインインされます。この場合は **パスワードをお忘れですか？** のリンクも表示されません。

## パスワードを再設定する

1. サインイン画面で **パスワードをお忘れですか？** を選びます。
2. メールアドレスを入力して **再設定リンクを送信** を選びます。
3. 届いたメールのリンクを開き、新しいパスワード（8 文字以上）を設定します。リンクの有効期限は 1 時間です。

パスワードを再設定すると、すべてのデバイスからサインアウトされます。

「パスワード再設定用のトークンが無効です」は、リンクの期限が切れているか、すでに使われているときに表示されます。再設定リンクをもう一度リクエストしてください。

**パスワードをまだ設定していない場合**: Google や GitHub で登録したアカウントにもパスワードを追加いただけます。[アカウント › セキュリティ](https://deniai.app/account/security) の **パスワードを設定** から再設定リンクをリクエストしてください。

## 二要素認証

### オンにする

1. [アカウント › セキュリティ](https://deniai.app/account/security) の **二要素認証** を開きます。
2. **オンにする** を選び、パスワードを入力します。
3. Google Authenticator や 1Password などの認証アプリで QR コードを読み取ります。読み取れない場合は、コードの下に表示されるキーを入力します。
4. 認証アプリに表示された 6 桁のコードを入力します。
5. バックアップコードを **コピー** か **ダウンロード** で保存します。バックアップコードは一度しか表示されません。

二要素認証で保護されるのは、パスワードやメールのサインインリンクを使ったサインインです。そのため、オンにするにはパスワードが必要です。Google や GitHub で登録した場合は、先に[パスワードを設定](#パスワードを再設定する)してください。Google、GitHub、パスキーでサインインするときはコードを求められません。

オフにするときは、同じカードで **オフにする** を選び、パスワードを入力します。

### コードを入力してサインインする

二要素認証がオンになっているアカウントでは、パスワードを入力したあとや、メールのサインインリンクを開いたあとにコードを求められます。
**二要素認証** の画面で、認証アプリに表示されている 6 桁のコードをご入力ください。

- **このデバイスを30日間信頼する** にチェックを入れると、このブラウザーでは 30 日間コードの入力が不要になります。
- コードの入力画面は 10 分で期限が切れます。「2段階認証のセッションが切れました。もう一度ログインしてください」と表示されたら、サインインからやり直してください。
- 間違ったコードを何度も入力すると、「認証の失敗が続いたため、アカウントが一時的にロックされました。…」と表示されます。しばらく待ってから、もう一度お試しください。

### バックアップコード

**二要素認証** の画面で **代わりにバックアップコードを使う** を選び、バックアップコードを 1 つ入力します。
バックアップコードはそれぞれ 1 回しか使えません。残りのコードはスマートフォンとは別の安全な場所に保管してください。

新しいコードが必要なときは、[アカウント › セキュリティ](https://deniai.app/account/security) で **バックアップコードを再発行** を選び、パスワードを入力します。これまでのコードは使えなくなります。

### 認証アプリの端末をなくしたとき

- バックアップコードでサインインしてください。
- 過去 30 日以内に **このデバイスを30日間信頼する** にチェックを入れたブラウザーでは、コードなしでサインインできる場合があります。
- どちらも使えない場合は、[お問い合わせ](https://deniai.app/ja/contact)ください。

## それでもサインインできないとき

[お問い合わせ](https://deniai.app/ja/contact)ください。使ったサインイン方法と、表示されたエラーメッセージをそのままお知らせください。
