Deni AI がチャットなどのデータをどう扱うか、またデータをダウンロード・削除する方法をまとめています。
正式な内容は [プライバシーポリシー](https://deniai.app/ja/legal/privacy-policy) に定めています。

<Callout title="秘密情報はチャットに貼り付けないでください">
  パスワード、API キー、その他の秘密情報はチャットに入れないでください。
  送信したメッセージは、回答を生成するために AI モデルの提供者へ送られます。
</Callout>

## チャットはモデルの学習に使われますか？

使われません。Deni AI は会話を自社モデルの学習には使いません。
また、会話を広告のターゲティングに使うこともありません。

ただし、サービスの運用、アカウントの保護、不正防止のために、アカウント、利用状況、請求の情報と、送信したコンテンツが処理されることがあります。

## メッセージを処理する事業者

メッセージを送信すると、プロンプト、会話の文脈、添付ファイルが、選んだモデルの提供者へ送られます。
送り先はモデルによって異なり、OpenAI、Anthropic、Google、Groq、xAI、OpenRouter、またはそのモデルを配信するためのルーターやゲートウェイです。

- ウェブ検索を有効にすると、検索クエリと関連する文脈が Exa などの検索提供者へ送られることがあります。
- モデルの提供者は回答を生成するために内容を処理します。提供者ごとに独自のプライバシーポリシーやデータの保持方針が定められている場合があります。

## Deni AI に保存されるデータ

| データ | 例 |
| --- | --- |
| アカウント | 名前、メールアドレス、アバター、サインイン方法 |
| 送信したコンテンツ | プロンプト、チャットメッセージ、アップロードしたファイルや画像、保存したメモリ、カスタム指示、プロジェクトの説明や指示 |
| 利用状況とデバイス | IP アドレス、ブラウザー、日時、機能の利用状況、エラーログ、セキュリティアクティビティ |
| チーム | チーム名、メンバー、役割、招待、監査ログ |
| 請求 | プランの状態、サブスクリプションの ID。カード情報は Stripe が扱い、Deni AI には保存されません。 |

データは、アカウントが有効な間と、サービスの提供に必要な期間、保持されます。
ゲストアカウントはこれより早く削除されることがあります。

チームでは、メンバーが役割に応じて、チームプロジェクトなどの共有コンテンツを見られます。
Deni AI に覚えさせた内容を管理する方法は、[メモリとプロジェクト](/ja/chat/memory-and-projects) で説明しています。

## チャットを削除する

1. サイドバーで、チャットの横にある **⋯** メニューを開きます。
2. **削除** を選びます。

確認画面は出ず、チャットはすぐに削除されます。チャットに添付したファイルも一緒に削除されます。

## データをダウンロードする

プロフィール、チャット、メモリ、プロジェクト、セキュリティアクティビティの JSON コピーをダウンロードいただけます。
パスワードや API キーなどの秘密情報は含まれません。

1. [アカウント](https://deniai.app/account/settings) を開きます（サイドバーのアカウントメニューからも開けます）。
2. **データをダウンロード** で **JSONをエクスポート** を選びます。
3. 準備ができたら **ダウンロード** を選びます。

エクスポートの準備には数分かかることがあります。準備中はこのページを離れても問題ありません。
できあがったエクスポートは 7 日間ダウンロードいただけます。表示された日時までにダウンロードするか、あとで **再エクスポート** を選んでください。

このファイルは別の Deni AI アカウントにインポートいただけます。手順は [ChatGPT や Claude の会話をインポートする](/ja/chat/import-conversations) にあります。

## アカウントを削除する

アカウントを削除すると、アカウントと関連データが完全に削除されます。この操作は取り消せません。
残しておきたいデータがある場合は、先に [データをダウンロード](#データをダウンロードする) してください。

1. [アカウント › セキュリティ](https://deniai.app/account/security) を開きます。
2. **危険な操作** で **アカウントを削除** を選びます。
3. パスワードでサインインしている場合はパスワードを入力し、削除を確定します。

次の場合は、まだアカウントを削除できません。

| 状況 | 対応 |
| --- | --- |
| 有効なサブスクリプションがある | 先に [設定 › 請求](https://deniai.app/settings/billing) で解約してください。 |
| サブスクリプションが終了予定 | 終了まで待つか、**返金なしで今すぐ削除** を選びます。サブスクリプションが終了しても、アカウントは自動的には削除されません。 |
| 未確定の利用料金や未払いの請求がある | 請求が確定し、支払いが完了するまでお待ちください。 |
| チームのオーナーである | 先に[チームを削除する](/ja/teams/pro-for-teams#チームを削除する)か、所有権を別のメンバーに移してください。 |

法令、請求、セキュリティ、不正防止のために必要な記録は、削除後も保持される場合があります。
アカウントに登録したアドレスから contact@deniai.app へメールして、削除をご依頼いただくこともできます。

## その他のプライバシーに関する依頼
