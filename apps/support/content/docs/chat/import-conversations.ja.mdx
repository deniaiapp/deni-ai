---
title: ChatGPT や Claude の会話をインポートする
description: ChatGPT、Claude、別の Deni AI アカウントの会話履歴を Deni AI に取り込む方法です。
---

エクスポートファイルを使うと、これまでの会話を Deni AI に取り込んでいただけます。
取り込んだ会話は通常のチャットとしてサイドバーに並びます。

インポートできるのは次のファイルです。

| 取り込み元 | アップロードするファイル |
| --- | --- |
| ChatGPT | データエクスポートに含まれる `conversations.json` |
| Claude | データエクスポートに含まれる `conversations.json` |
| Deni AI | アカウントのエクスポートでダウンロードした JSON ファイル |

ゲストアカウントではインポートできません。サインインしてから操作してください。

## エクスポートファイルを用意する

1. 各サービスの設定から、データのエクスポートをリクエストします。
2. 準備ができたらダウンロードし、ZIP を展開します。
3. 中にある `conversations.json` を探します。

アップロードするのは ZIP ファイルではなく `conversations.json` そのものです。

Deni AI からエクスポートする方法は、[データをダウンロードする](/ja/account/data-and-privacy#データをダウンロードする)で説明しています。

## ファイルをアップロードする

1. [設定 › インポート](https://deniai.app/settings/import) を開きます。
2. **ファイルを選択** を押して、JSON ファイルを選びます。
3. 完了すると「N件のチャット(N件のメッセージ)をインポートしました。」と表示されます。

取り込んだチャットはすぐにサイドバーに表示されます。

## 取り込まれる内容

| 項目 | 扱い |
| --- | --- |
| タイトル | そのまま引き継がれます。タイトルがない会話は「Imported Chat 1」「Imported Chat 2」のような名前になります。 |
| 日時 | 元の作成日時と最終更新日時が引き継がれるため、サイドバーでは過去のチャットの間に並びます。 |
| メッセージ | ご自身のメッセージと AI の返信が、テキストとして取り込まれます。ChatGPT のコードブロックはコードブロックのままです。 |
| 編集・再生成したメッセージ | 各会話の最新の分岐だけが取り込まれます。それ以前のバージョンは含まれません。 |
| Claude の思考過程 | 返信の推論として取り込まれます。 |
| ツールの呼び出しと結果 | 取り込まれません。 |
| 画像・添付ファイル | 取り込まれません。元の位置には `[image attachment omitted]` や `[attachment omitted: ファイル名]` のような注記が入ります。 |
| Claude が読み取った文書のテキスト | Claude のエクスポートに文書のテキストが含まれている場合は、`[Attached file: ファイル名]` に続けてそのテキストが取り込まれます。 |

取り込んだチャットはどのプロジェクトにも入りません。
Deni AI のエクスポートにはメッセージのテキストしか含まれていないため、取り込めるのもテキストだけです。

## 上限

- ファイルは 1 つずつ、25 MB まで
- 1 ファイルあたり会話 20,000 件、メッセージ 200,000 件まで（Claude の添付ファイルなどメッセージ内の要素も 200,000 件に含めて数えます）
- インポートは 1 時間に 5 回まで

インポートは全件まとめて行われます。途中で失敗した場合、チャットは 1 件も追加されません。

## 同じファイルを 2 回インポートした場合

<Callout title="2 回インポートすると重複します">
  取り込んだチャットはアカウントに追加されるだけで、既存のチャットとは統合されません。
  同じファイルをもう一度インポートすると、すべてのチャットがもう 1 つずつ作られます。不要な分はサイドバーから削除してください。
</Callout>

## うまくいかないとき

**「有効なJSONファイルではありません。」と表示される**

選んだファイルが JSON ではありません。エクスポートの ZIP を展開し、`conversations.json` をアップロードしてください。

**「インポートできる会話が見つかりませんでした。」と表示される**

Deni AI が読み取れる会話がファイルに含まれていません。エクスポートの中の別のファイルではなく `conversations.json` を選んでいるかご確認ください。

**インポート後に警告が表示される**

使えるメッセージがない会話（空の会話や、ツールの出力しかない会話など）は取り込まれず、警告として一覧に表示されます。警告では、それぞれの会話がファイル内での順番で示されます。

**データが大きすぎるというエラーが出る**

ファイルが 25 MB を超えているか、会話が 20,000 件、またはメッセージが 200,000 件を超えています。

**「リクエストが多すぎます。しばらくしてからもう一度お試しください」と表示される**

直近 1 時間に 5 回インポートしています。時間をおいてからもう一度お試しください。

**「インポートに失敗しました。」と表示される**

ほかの理由で失敗しました。チャットは追加されていないので、もう一度お試しください。何度やっても失敗する場合は [お問い合わせ](/en/contact) からご連絡ください。
