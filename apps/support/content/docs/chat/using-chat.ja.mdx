[deniai.app](https://deniai.app) の Deni AI チャットで、よく使う機能をまとめています。

## メッセージを送る

メッセージ欄に入力して **Enter** を押すと送信されます。**Shift+Enter** で改行します。スマートフォンやタブレットでは **Enter** で改行されるので、送信ボタンをタップしてください。

回答を書いている間は、送信ボタンが **停止** に変わります。選んだときの動きは[回答を止める](#回答を止める)で説明しています。

**音声入力** のマイクのボタンを使うと、話した内容をメッセージとして入力いただけます。

## モデルを選ぶ

メッセージ欄のモデル名を選ぶと、モデルの選択画面が開きます。名前で検索するか、**注目**、OpenAI、Anthropic、Google のプロバイダーごとにお探しいただけます。

選んだモデルは、同じブラウザーでは次のチャットでも選ばれたままになります。チャットごとには保存されません。既定のモデルを決めたプロジェクトでは、そのプロジェクトで始めた新しいチャットがそのモデルで始まります。

選択画面には次の表示が出ます。

- **ティア** のバッジが付いたモデルは、1 トークンあたりの利用枠を多く使います。バッジにカーソルを合わせると、何倍になるかが表示されます。ティアごとの倍率は [モデルのティア](/ja/billing/plans-and-usage#モデルのティア) の表にあります。
- 緑の点はモデルが正常に動いていることを、警告のアイコンは今は使えないことを示します。
- **提供終了予定** と日付のバッジが付いたモデルは、提供が終わる予定です。

ご利用いただけるモデルはプランによって違います。

| プラン | モデル |
| --- | --- |
| ゲスト | GPT-6 Luna |
| Free | GPT-6 Luna、Claude Haiku 5.5、Gemini 3.8 Flash |
| カードを確認した Free、または Go | ほとんどのモデル |
| Plus | Pro 限定のモデルを除くすべてのモデル |
| Pro | すべてのモデル |

プランごとの違いは [プランと使用量](/ja/billing/plans-and-usage) にまとめています。

### 推論の強度

推論の強度のメニュー（脳のアイコン）で、モデルが回答する前にどれだけ考えるかをお選びいただけます。選べるのは **なし**、**最小**、**ライト**、**中**、**高**、**超高**、**最大** です。
モデルによって選べる段階は違い、推論の強度に対応していないモデルではメニューが灰色になります。既定は、選べる場合は **高** です。

強度を上げると、難しい質問によい回答が返ることがあります。そのかわり、時間がかかり、利用枠も多く使います。スマートフォンでは、このメニューは **+** のメニューの中にあります。

## ファイルを添付する

ファイルは次の方法で添付いただけます。

- **+** から **写真やファイルを追加** を選ぶ
- ファイルをページにドラッグする
- ファイルや画像をメッセージ欄に貼り付ける

ファイルは追加した時点でアップロードが始まります。「アップロード中...」が消えてから送信してください。

| 種類 | 形式 | サイズの上限 |
| --- | --- | --- |
| 画像 | JPEG、PNG、WebP。HEIC、GIF、AVIF、BMP は、ブラウザーが読み込める場合にブラウザーで変換します。 | 10 MB |
| PDF | PDF | 10 MB |
| テキストとコード | `.txt`、`.md`、`.csv`、`.json`、`.yaml`、`.html`、`.js`、`.ts`、`.py`、`.sql`、`.srt` などのファイル | 2 MB |

SVG、Word、Excel、ZIP などのファイルは添付できません。先に PDF かテキストで保存してください。

テキストとコードのファイルは、文章としてメッセージに加えられます。1 つのメッセージでモデルが読むのは、画像と PDF が 20 個（合計 20 MB）まで、テキストファイルが 20 個（合計 40 万文字）までです。
それより長いテキストファイルは途中で切られます。

添付したファイルは保存容量を使います（ゲストは 20 MB、Free は 100 MB、Go は 200 MB、Plus は 500 MB、Pro は 1 GB）。使っている量は [設定 › 請求](https://deniai.app/settings/billing) の **添付ファイルの保存容量** でご確認いただけます。チャットを削除すると、そのチャットのファイルも削除されます。

アップロードに失敗したときの対処法は、[ファイルのアップロード](/ja/chat/troubleshooting#ファイルのアップロード)にあります。

## Web を検索する

最新の情報が必要な質問では、モデルが自分で Web を検索することがあります。
必ず Web の情報を使って回答させたいときは、送信する前に **+** から **検索** をお選びください。回答に使った情報源は **ソース** に表示されます。

**詳細リサーチ**（**+** のメニューにあります）を使うと、モデルが何度も検索してページを開き、内容を照らし合わせて、要約、主な発見、リスク、ソースをまとめたレポートを書きます。通常の回答より時間がかかります。ゲストは詳細リサーチをご利用いただけません。

Web 検索は 1 回につき 10,000 ユニットの利用枠を使います。

メッセージにリンクを貼り付けて、そのページについてご質問いただくこともできます。モデルがページを開いて読みます。

### モデルからの質問

回答の前に、モデルがいくつか質問をすることがあります。質問は 1 つずつ表示され、選択肢からお答えいただけます。
答えたら **回答を送信** を選ぶか、**回答せずに続行** をお選びください。どちらかを選ぶまで、新しいメッセージは送れません。

## 回答に含まれるもの

- **コードブロック** にはコピーのボタンがあります。HTML、JSX、TSX のコードには **プレビュー** のボタンもあり、チャットの横のパネルでコードを動かせます。React のコードのプレビューで使えるのは `react` と `react-dom` だけです。
- Mermaid で書いた **図** は図として表示されます。
- **数式** は整えた形で表示されます。
- **グラフ、チェックリスト、計算機などの操作できる要素** は、役に立つときに表示されます。文章中心の回答にしたいときは、[外観](#外観)の **レイアウトとビジュアル** を **シンプル** にします。
- **ほかのサイトの画像** は **… から画像を読み込む** を選んだときだけ読み込まれます。
- **ほかのサイトへのリンク** は開く前に **リンクを開く** で確認を求められます。

## 回答を止める

回答を書いている間に **停止** を選びます。それまでに書かれた内容はチャットに残り、利用枠に数えられるのもその分だけです。

## 回答の再試行、改善、コピー

それぞれの回答の下には、次のボタンがあります。

- **再試行** のメニューでは、次の操作ができます。
  - 回答をどう直してほしいかを入力して **送信** を選ぶ
  - **再生成** で回答を作り直す
  - **回答を詳しくする** か **回答を短くする**
  - **Web検索を使う** か **詳細リサーチを実行**
  - **モデルを変更** して、別のモデルで回答し直す
- **コピー** で回答をコピーします。
- **読み上げる** で回答を読み上げます。ブラウザーが対応している場合だけご利用いただけます。

**再試行** で作り直しても、前の回答は消えずに残ります。回答の下の矢印で切り替えてご覧いただけます。

送ったメッセージはあとから編集できません。内容を変えたいときは、新しいメッセージをお送りください。

## チャットを整理する

チャットはサイドバーに、**ピン留め済み**、**今日**、**昨日**、それより前の順にまとめて表示されます。

チャットの横の **⋯** から、次の操作ができます。

- **詳細を編集**: タイトル、フォルダ、タグを変える
- **ピン留め** か **ピンを外す**
- **削除**: 確認なしで、チャットと添付ファイルをすぐに削除する

### フォルダ

サイドバーの **フォルダ** で **+** を選ぶと、フォルダを作成いただけます。
チャットをフォルダにドラッグすると、そのフォルダに入ります。フォルダから出すときは、**ここにドロップしてフォルダから外す** にドラッグします。

共通のファイルや指示でチャットをまとめたいときは、[プロジェクト](/ja/chat/memory-and-projects#プロジェクト)をご利用ください。

### チャットを検索する

サイドバーの **チャット検索** を選ぶか、**Ctrl+K**（Mac では **Cmd+K**）を押します。
検索の対象はチャットのタイトル、フォルダ、タグです。メッセージの本文は検索されません。

### キーボードショートカット

| ショートカット | 操作 |
| --- | --- |
| **Ctrl+K** / **Cmd+K** | チャット検索 |
| **Ctrl+Shift+C** / **Cmd+Shift+C** | 新しいチャット |
| **/** | メッセージ欄に移動 |
| **Esc** | メッセージ欄をたたむ |

文字を入力している間は、ショートカットは使えません。

## チャットをエクスポートする

開いているチャットで、右上の **チャットをエクスポート**（ダウンロードのアイコン）を選びます。

- **Markdownでエクスポート** で、会話を `.md` ファイルとしてダウンロードします。
- **JSONでエクスポート** で、すべてのメッセージを `.json` ファイルとしてダウンロードします。
- **PDFでエクスポート** を選ぶと、ブラウザーの印刷画面が開きます。そこで **PDF に保存** をお選びください。

Markdown と PDF に含まれるのは会話の文章だけで、添付ファイルや検索の結果は含まれません。

すべてのデータをまとめてダウンロードする方法は、[データとプライバシー](/ja/account/data-and-privacy#データをダウンロードする)で説明しています。
チャットを公開リンクで共有する機能はありません。

## 2 つのモデルを比べる

モデルの比較は Pro（Pro for Teams を含む）でご利用いただけます。

1. サイドバーの **モデルを比較する** を選びます。
2. **1つ目のモデル** と **2つ目のモデル** を選びます。2 つは別のモデルにしてください。
3. 質問を入力します。2 つのモデルが並んで回答します。

それぞれのモデルは別々に会話を続け、どちらの回答も利用枠に数えられます。比較ではファイルを添付できません。
左右それぞれの **生成設定** で、推論の強度、検索や詳細リサーチのオンとオフ、モデルが使えるツールを変更いただけます。

- **比較を保存** で保存すると、あとで **保存済みの比較** から開けます。保存していない比較はページを離れると消えます。
- **このチャットを続ける** で、片方を通常のチャットにできます。
- **新しい比較** で、最初からやり直せます。

1 つの比較には左右それぞれ 200 件ほどのメッセージまで入ります。それを超えたら、新しい比較を始めてください。

## リンクからチャットを始める

`https://deniai.app/new/` のあとにメッセージを付けたリンク（`https://deniai.app/new/この記事を要約して` など）を開くと、そのメッセージを入力した状態で新しいチャットが始まります。
`?webSearch=true` を付けると **検索** がオンになります。メッセージはご自身で送信するまで送られません。

## 外観

[設定 › 外観](https://deniai.app/settings/appearance) で、次の項目を変更いただけます。

- **言語**: 英語か日本語
- **モード**: ライト、ダーク、システム
- **レイアウトとビジュアル**: **リッチ** では、回答にグラフやチェックリストなどの操作できる要素が入ります。**シンプル** では、回答がほぼ文章だけになります。
- **カラーテーマ**: 配色を選ぶ

**レイアウトとビジュアル** はブラウザーに保存されます。ほかの端末ではもう一度設定してください。
