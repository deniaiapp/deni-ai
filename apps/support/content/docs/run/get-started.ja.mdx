Deni Run は [Deni AI](https://deniai.app/run) の中の Run モードとして統合されており、AI のチームメイトに仕事を任せられます。
チームメイトはそれぞれ専用のコンピューターで作業します。コンピューターには、お客さまのアカウント専用のブラウザー、ファイルのワークスペース、Linux のターミナルがあります。
調べもの、フォームの入力、ファイルの整理、スクリプトの実行を、ご自身のパソコンに触れずにお任せいただけます。

Deni Run は Deni AI のすべてのプランに含まれていて、Deni Run だけの料金はありません。Deni AI チャットや Flixa と同じ毎月の利用枠を使います。

## Deni Run を開く

1. [Deni AI](https://deniai.app) にサインインし、サイドバーから **Run** に切り替えます（または [`/run`](https://deniai.app/run) を開きます）。
2. Deni AI のアカウントとプランがそのまま使われるため、別のアカウントへのサインインや連携は不要です。

プランの変更や詳しい使用量の確認は、Deni AI の [設定 › 請求](https://deniai.app/settings/billing) から行えます。

<Callout title="ゲストアカウントでは Deni Run を使えません">
  Deni AI のゲストアカウントは Run モードを利用できません。先に Deni AI にご登録ください。ゲストのチャットを引き継いで登録する方法は、[チャットを引き継ぐ](/ja/account/guest-accounts#チャットを引き継ぐ)にあります。
</Callout>

## チームメイトに仕事を任せる

Deni Run には Chief、Research、Operations などのチームメイトが用意されています。ご自身でチームメイトを作るときは、**チームメイトを追加** を選びます。
チームメイトはそれぞれメモリを持ち、共有のスキルやスケジュール実行されるルーティンを設定できます。

1. チームメイトを選び、任せたい仕事を書きます。調べもの、フォームの入力、ファイルの整理などです。
2. チームメイトが作業している画面を、その場でご覧いただけます。
3. 確認を求められたら、危険な操作を承認します。結果はワークスペースに保存されます。

サイトへのサインイン、二要素認証のコード、CAPTCHA が必要になったときは、画面のブラウザーをご自身で操作してその手順を済ませ、チームメイトに戻します。

### 承認

読み取りだけの操作は確認なしで実行されます。
ファイルの削除や、内容を変えるコマンドの実行など、それ以外の操作は承認を待ちます。信頼できる操作で確認を省きたいときは、承認の画面で **常に許可** を選びます。
ご自身で追加した MCP サーバーの呼び出しは、そのツールを許可していない限り、毎回承認が必要です。

### モデル

モデルは選択画面で選びます。

| モデル | もとのモデル | 向いている用途 |
| --- | --- | --- |
| Run | Claude Sonnet 5.5 | 速く、利用枠の使用量が少ない |
| Run+ | Claude Opus 5.5 | 難しい仕事 |

どちらのモデルにも、推論の強度が **デフォルト**、**高**、xhigh、**最大** の 4 段階あります。強度を上げるほど、利用枠を多く使います。選択画面には、それぞれの選択肢が Run のデフォルトのおよそ何倍の利用枠を使うかが表示されます。

### チームメイトの上限

| プラン | チームメイト |
| --- | --- |
| Free | 5 人まで |
| Go | 10 人まで |
| Plus | 15 人まで |
| Pro | 25 人まで |

上限に達すると「チームメイトの上限に達しました」と表示されます。チームメイトを増やすには、Deni AI のプランをアップグレードしてください。

### ファイル

1 つのメッセージに 10 MB 以下のファイルを 10 個まで添付できます。添付したファイルはチームメイトのワークスペースに保存されます。

## アプリを接続する

**Run 設定** で外部の MCP サーバーやアプリを接続すると、チームメイトが代わりに検索、閲覧、下書き、送信をできるようになります。

1. Run のサイドバーで **Run 設定** を開き、**コネクタを探す** を選びます（または **コネクタ (MCP)** の **カスタムサーバー** から追加します）。
2. コネクタを選び、**インストール** を選びます（サインインが必要な場合は案内に従って認証します）。

誰も見ていないときに裏で動く作業では、接続したアプリの読み取り専用のツールだけを使えます。

### Discord

Discord のダイレクトメッセージで、チームメイトと話すこともできます。

1. **Run 設定** の **Discord** で、**リンクコードを作成** を選びます。
2. 表示されたコードを、Discord のダイレクトメッセージで Deni Run のボットに送ります。コードは 1 回しか使えず、10 分で期限が切れます。

Discord のサーバーのチャンネルには対応していません。サイトへのサインインなど、ブラウザーが必要な手順は Deni AI の Run モードでお済ませください。

## 利用枠

Deni Run は Deni AI のプランの毎月の利用枠を、Deni AI チャットや Flixa と共有して使います。数えるのは次の 3 つです。

- モデルの利用
- チームメイトのブラウザーを使った時間
- チームメイトのコンピューターを使った時間

Deni Run は各手順を実行したあとでコストを数えます。そのため、残りの利用枠を少し超えて作業が進むことがあります。

| | Free | Go | Plus | Pro |
| --- | --- | --- | --- | --- |
| 毎月の利用枠（共有） | 2,000 万ユニット | 6,000 万ユニット | 2 億ユニット | 4 億ユニット |

有料プランの利用枠は請求期間に合わせて、プランを始めた日を基準に毎月リセットされます。無料プランは毎月 1 日 00:00（UTC）にリセットされます。
今月使った利用枠の内訳（Deni AI Chat、Flixa、Deni Run）の確認やプラン変更は、[設定 › 請求](https://deniai.app/settings/billing) から行えます。

利用枠を使い切ると「今月の利用枠を使い切りました」と表示され、リセットまでチームメイトは作業できません。
利用量のリセット権でリセットされるのは Deni AI チャットと Flixa の使用量だけで、Deni Run の使用量はリセットされません。Max Mode のクレジットも Deni Run には使われません。

## データの扱い

- ワークスペースのファイル、ブラウザーのセッション、コンピューターは、アカウントごとに分けられています。
- メッセージは OpenRouter と、OpenRouter が振り分けるモデルの提供元で処理されます。モデルの学習には使われません。
- Deni Run はデータを広告に使ったり販売したりしません。
- 接続した MCP サーバーのトークンは、暗号化して保存されます。
- **設定 › アカウント** から Deni AI のアカウントを削除すると、Deni Run のチームメイト、会話、ジョブ、コネクタ、ワークスペースのファイルもあわせて削除されます。詳しくは [データの扱いとプライバシー](/ja/account/data-and-privacy#アカウントを削除する) をご覧ください。
