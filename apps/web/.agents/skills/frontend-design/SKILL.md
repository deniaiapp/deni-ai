name: frontend-design
description: Design or restyle frontend interfaces when the task calls for visual design work.
license: Complete terms in LICENSE.txt
---

Build working interfaces suited to the product, audience, and requested visual
direction. Preserve the existing design system for incremental changes; use a
distinctive, cohesive direction when designing a new surface or a redesign.

Choose typography, spacing, color, and hierarchy together. Use motion and
decorative effects only when they support the experience. Avoid imposing a font,
palette, or layout preference on every task.

Cover responsive layout, keyboard access, focus, contrast, and relevant loading,
empty, and error states. Check the affected interface in the running app and
resolve issues introduced by the change before handing it back.
